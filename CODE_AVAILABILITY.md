# Code availability

Custom scripts used for single-cell RNA-sequencing integration, quality control, copy-number-variation inference, epithelial-cell reclustering, BACH1-focused pySCENIC analysis, scATAC-seq motif and peak-to-gene analysis, pathway enrichment, spatial-transcriptomic analysis and figure generation are available at **[GitHub repository URL]**. A version of record will be archived at Zenodo under **[Zenodo DOI]**. The repository includes analysis scripts, fixed parameter settings, software environment specifications, source data for the reported figures and instructions for reproducing the principal analyses.

The repository does not redistribute raw sequencing data or large third-party reference databases. Public data are available under GSE131907, GSE274934 and E-MTAB-13530. Reference files can be obtained from their original providers using `scripts/download_reference_resources.py`.
