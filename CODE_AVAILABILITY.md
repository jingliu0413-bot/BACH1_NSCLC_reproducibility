# Code availability

Custom scripts used for single-cell RNA-sequencing integration, quality control, copy-number-variation inference, epithelial-cell reclustering, external BACH1 activity scoring, pySCENIC seed-stability analysis, TCGA score-association replication, scATAC-seq motif/target-window analysis, pathway enrichment, spatial-transcriptomic sensitivity analysis, figure generation and supplementary-table preparation are available at **https://github.com/jingliu0413-bot/BACH1_NSCLC_reproducibility**. A version of record will be archived at Zenodo under **[Zenodo DOI]** after the submission version is frozen. The repository includes analysis scripts, fixed parameter settings, software environment specifications, lightweight source tables for the current IF5 submission and instructions for reproducing the principal analyses.

The repository does not redistribute raw sequencing data or large third-party reference databases. Public data are available under GSE131907, GSE274934 and E-MTAB-13530. Reference files can be obtained from their original providers using `scripts/download_reference_resources.py`.
