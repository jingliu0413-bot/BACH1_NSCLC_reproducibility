# IF5 Submission Source Tables

These lightweight tables were copied from the 2026-09-11 IF5-oriented submission output directory. They are included so reviewers can inspect the key numerical outputs without downloading raw sequencing matrices or large intermediate objects.

The tables include current Figure 2, Figure 3 and Figure 4 source summaries, matched-null diagnostics, TCGA model outputs, external BACH1 activity scores, per-patient QC-adjusted models and spatial sensitivity summaries. They are generated outputs, not raw data.
