# Manuscript Submission Source Tables

These lightweight tables are the source summaries for the final spatially extended manuscript package prepared on 2026-10-05. They are included so reviewers can inspect the key numerical outputs without downloading raw sequencing matrices or large intermediate objects.

The tables include current Figure 2, Figure 3, Figure 4 and Figure 5 source summaries, matched-null diagnostics, TCGA model outputs, external BACH1 activity scores, per-patient QC-adjusted models and spatial sensitivity summaries. The `spatial_state_deoverlap_*` files record the independent GSE292299 state-score de-overlap sensitivity, including score coverage, removed genes, residual correlations and reproducibility checks against the locked spatial score table. They are generated outputs, not raw data.
